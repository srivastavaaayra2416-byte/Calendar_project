# Problem Statement
People often struggle to keep track of simple daily tasks and events without relying on complex, heavy web-based calendars that require internet access. There is a need for a lightweight, offline, desktop-based event tracker.

# Scope of the project
The project provides a graphical interface displaying a standard calendar. Users can navigate chronologically and select days to store custom text-based events. The scope is limited to local offline usage.

# Target Users
* Students needing a simple assignment tracker.
* Professionals requiring quick, offline desktop notes.
* General users who prefer lightweight desktop applications.

# High-Level Features
* Dynamic calendar generation.
* Graphical User Interface (Tkinter).
* CRUD logic (Create and Read events).
* File-based data persistence (.txt).
